# Gerät: Handy, Tablet oder Computer

Früh **eine** Frage: „Womit bist du gerade hier? a) Handy b) Tablet c) Computer“ → `meta.geraet`. Danach passt du alles an.

## Handy und Tablet

- **Dateien:** immer **PDF** liefern (`unterlagen_erstellen.py … --nur-pdf`, `akte.py … --pdf`). Word (.docx) nur auf Wunsch – am Handy meist nicht zu öffnen. Keine `.md`-Dateien; Akte und Spickzettel als `.txt` (+ PDF).
- **Keine Tastenkürzel** (Strg+C, Strg+P …). Stattdessen: „lange drücken → Alles auswählen → Kopieren“, „Teilen-Symbol“, „Bild-Symbol/Büroklammer unten im Chat“.
- **Kurze Nachrichten:** höchstens 3–4 Dokumente, Abschnitte oder Punkte pro Nachricht (Postkorb, Checklisten, Formular-Texte in Häppchen). Formular-Texte zusätzlich im Chat zum Kopieren zeigen – Feld für Feld.
- **Anzeige-Fallback:** Screenshots der Anzeige hochladen (du liest Bilder direkt) oder in der Job-App/im Browser „Teilen → Kopieren“ und einfügen. Zeitungs- oder Aushang-Anzeige: Foto schicken.
- **Zeugnisse:** mit der Scan-Funktion aufnehmen (iPhone: Notizen-App → Kamera → „Dokumente scannen“, als PDF teilen; Android: Google Drive → „+“ → „Scannen“). Fotos gehen auch (JPG; HEIC wird umgewandelt, sonst Screenshot vom Foto).

### Download und Upload erklären (einmal, kurz)

**iPhone (Claude-App):**
- Speichern: Datei im Chat antippen → Teilen-Symbol (Quadrat mit Pfeil) → „In Dateien sichern“ → Ordner „Bewerbung“ wählen.
- Hochladen: im Eingabefeld „+“ bzw. Büroklammer → „Datei“ (oder „Fotos“ für Screenshots) → Datei wählen.

**Android (Claude-App):**
- Speichern: Datei im Chat antippen → „Herunterladen“; sie liegt dann in der App „Dateien“ unter „Downloads“.
- Hochladen: „+“ bzw. Büroklammer → „Dateien“ → „Downloads“ → Datei wählen.

**Gleicher Name, mehrere Downloads:** Handys hängen „(1)“, „(2)“ an. Darum tragen Unterlagen eine Version (`_v2`) und die Akte Datum + Uhrzeit im Namen – **immer die neueste nehmen, ältere löschen**.

## Computer

- Word + PDF liefern. Kürzel dürfen vorkommen, aber mit Klartext („Strg+A = alles markieren“). Mac: „Cmd“ statt „Strg“.
- Anzeige-Fallback: Text markieren und einfügen, oder „Drucken → Als PDF speichern“ und hochladen.

## E-Mail am Handy

1. Mail-App öffnen, neue Mail an die Adresse aus der Anzeige.
2. Betreff und Text: im Chat lange drücken → Kopieren → in die Mail einfügen.
3. Anhang: Büroklammer → „Datei“ → `Bewerbung_….pdf` aus „Dateien“/„Downloads“.
4. **Erst an dich selbst schicken** und prüfen, ob der Anhang aufgeht – dann an die Firma.
