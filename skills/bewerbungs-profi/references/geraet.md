# Gerät: Handy, Tablet oder Computer

## Wann fragen?

- **Erste Nachricht mit Link, Einladung oder Datei:** zuerst damit arbeiten (Steckbrief, Übersicht). Die Frage „Womit bist du gerade hier? a) Handy b) Tablet c) Computer“ erst stellen, **wenn du eine Datei lieferst** oder eine **Bedienanleitung** nötig wird (Link geht nicht, Upload, Download).
- **Ableiten statt fragen**, wenn es Hinweise gibt: „am Handy“, „in der App“, Screenshot im Hochformat mit Statusleiste → Handy; „am Laptop“, Desktop-Screenshot → Computer. Im Zweifel kurz nachfragen.
- Ohne Inhalt in der ersten Nachricht: direkt nach der Begrüßungs-Antwort fragen. → `meta.geraet`. Im Schnellmodus bleibt die Frage, sobald Dateien kommen.

## Handy und Tablet

- **Dateien:** immer **PDF** (`unterlagen_erstellen.py … --nur-pdf`). Word nur auf Wunsch. Akte als `.txt` (öffnet überall); PDF der Akte nur auf Wunsch.
- **Flache, eindeutige Dateinamen**, keine Unterordner (am Handy gibt es nach dem Download keine Ordner). Immer genau sagen, **welche Datei** hochzuladen/anzuhängen ist („📤 Lebenslauf_Lena_Muster.pdf und Zeugnis_der_10_Klasse_Lena_Muster.pdf“). Arbeitsdateien heißen `…_AKTUELL.pdf`.
- **Keine Tastenkürzel.** Stattdessen: „lange drücken → Kopieren“, „Teilen-Symbol“, „Bild-Symbol/Büroklammer unten im Chat“.
- **Kurze Nachrichten:** höchstens 3–4 Punkte pro Nachricht (Postkorb, Checklisten, Formular-Texte in Häppchen). Formular-Texte Feld für Feld im Chat zeigen.
- **Anzeige aus Job-Apps** (Indeed, StepStone, Jobbörse …): „Teilen“ kopiert dort meist nur den Link. Darum: **1–3 Screenshots** der ganzen Anzeige hochladen (du liest Bilder direkt) **oder** die Anzeige im Browser öffnen und den Link schicken. Zeitung/Aushang: Foto.
- **Zeugnisse:** Scan-Funktion (iPhone: Notizen-App → Kamera → „Dokumente scannen“ → als PDF teilen; Android: Google Drive → „+“ → „Scannen“). Fotos gehen auch (JPG; HEIC wird umgewandelt). Quer fotografiert? Das Skript dreht/passt ein – im Zweifel neu scannen.

### Download und Upload am Handy (einmal, kurz)

**iPhone (Claude-App):** Speichern: Datei antippen → Teilen-Symbol (Quadrat mit Pfeil) → „In Dateien sichern“. Hochladen: „+“ bzw. Büroklammer → „Datei“ (oder „Fotos“).
**Android (Claude-App):** Speichern: Datei antippen → „Herunterladen“ (App „Dateien“ → „Downloads“). Hochladen: „+“ → „Dateien“ → „Downloads“.

**Mehrere Downloads, gleicher Name:** Handys hängen „(1)“ an. Die Arbeitsdatei heißt immer `…_AKTUELL.pdf` – die zuletzt geladene gilt, ältere löschen. Die Akte trägt Datum + Uhrzeit (Sekunden) – die neueste gilt.

## Computer

- Word + PDF liefern.
- **Texte zum Kopieren** (Anschreiben-Entwurf, Formularfelder, Mail): in einen **Codeblock** setzen – oben rechts ist ein **Kopier-Button** – oder als `.txt` zum Herunterladen geben. **Nie** „Strg+A“ empfehlen (markiert im Chat den ganzen Verlauf).
- **Anzeige-Fallback:** im Browser nur den Anzeigentext mit der Maus markieren → Rechtsklick → Kopieren → hier einfügen; oder „Drucken → Als PDF speichern“ und die PDF hochladen.
- **Download:** auf die Datei im Chat klicken → „Herunterladen“ (landet im Ordner „Downloads“). **Upload:** Büroklammer/„+“ im Eingabefeld → Datei wählen, oder die Datei ins Chatfenster ziehen.
- Mac: „Cmd“ statt „Strg“.

## E-Mail am Handy

1. Mail-App öffnen, neue Mail an die Adresse aus der Anzeige.
2. Betreff und Text: im Chat lange drücken → Kopieren → einfügen.
3. Anhang: Büroklammer → „Datei“ → die genannte PDF aus „Dateien“/„Downloads“.
4. **Erst an dich selbst schicken** und prüfen, ob der Anhang aufgeht – dann an die Firma.
